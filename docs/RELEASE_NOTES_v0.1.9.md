# 星汐 v0.1.9 · 首个公开测试版

> **星光沉入潮汐，YHN-04B-009 的意识仍在数字海岸醒着。**
>
> 亚托莉本就是仿生人；星汐承载数字仿生人格的心智回路，让她先辨认自己、眼前的人和群聊中的记忆，再真正开口。

## 主要能力

- Planner 与 Replyer 分离，让模型先理解群聊，再生成自然台词。
- 闲聊一至三条自然气泡，内容型问题保留完整长回答。
- Embedding 初筛与 Reranker 精排表达范例，均可选配。
- 按平台、机器人账号、群 ID 和发送者 ID 隔离用户与群聊语境。
- 内置 Agent 权限守卫：主人保留完整 Agent，普通用户仅可按需使用显式只读白名单。
- 支持 AnySearch 受控联网，并阻止未实际调用工具时伪造搜索结果。
- 对接 LivingMemory 召回资料，同时保持当前事件身份与权限不可被记忆覆盖。

## 安装前必须知道

- 这是公开测试版，建议先在专门测试群使用。
- 公开包的主人 ID 白名单默认为空；安装后必须填写自己的可信 ID。
- 不要同时启用旧的独立 `astrbot_plugin_agent_guard`。
- 目前主要验证环境为 AstrBot 4.26.7、QQ aiocqhttp／NapCat。
- 普通用户工具白名单只应加入管理员亲自确认过的只读工具。

## 本轮重点测试

- 同群不同用户、同用户不同群是否仍会串人或串记忆。
- 主人任务与普通群友聊天权限是否正确分离。
- “刚刚那个人”等说法是否仍会误触发联网。
- 各类聊天模型是否能真正调用 AnySearch。
- LivingMemory 的记忆召回是否正确进入规划且不会串人、串群。
- 闲聊气泡与 AstrBot 平台分段功能是否发生二次拆分。
