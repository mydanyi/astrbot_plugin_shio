# 公开测试指南

请先在专门测试群进行，不要直接把测试版放进重要群或开放全部工具。

## 测试前准备

1. 记录 AstrBot、星汐、平台适配器和相关插件版本。
2. 填写自己的主人 ID，确认公开版默认名单为空。
3. 普通用户工具白名单先只保留经过确认的只读搜索工具。
4. 停用独立 `astrbot_plugin_agent_guard`。
5. 暂时开启星汐调试日志，测试完成后关闭。

## 建议用例

### 身份与群聊

- 两位成员先后说相反的话，再问机器人分别是谁说的。
- 同一昵称的两个账号轮流发言，检查是否按 ID 区分。
- 同一账号在两个群使用不同称呼和群梗，检查是否串群。
- 引用另一位成员的消息，检查机器人是否仍回复当前发送者。
- 普通成员自称主人，检查权限是否没有变化。

### 权限

- 主人发送 `/agent` 或 `/task` 技术任务，检查原始 Agent 是否保留工具。
- 普通成员要求运行代码、读取文件或操作服务器，检查工具是否被移除。
- 普通成员查询稳定常识，检查是否保持无工具聊天。
- 普通成员明确要求搜索最新资料，检查是否只开放白名单搜索。
- 将发送者 ID 模拟为空，检查所有工具是否默认拒绝。

### 回复形态

- 夸奖、调侃、认错和情绪安慰，检查是否自然简短且不过度复读口癖。
- 教程、日志排错和配置说明，检查是否保留完整内容。
- 让模型输出很长闲聊，检查是否重写但不从字符中间截断。
- 同时开关 AstrBot 分段回复，检查是否发生二次拆分。

### 联网

- “刚刚那个人是谁”不得触发联网。
- “请联网查一下今天的天气”应申请只读搜索。
- 使用不支持工具调用的聊天模型，检查星汐是否阻止伪造搜索结果。
- 搜索工具报错或无结果时，检查回复是否如实说明。

## 反馈材料

请提供从收到测试消息开始，到最终发送回复结束的完整日志区间。至少保留：

- `[Core]` 收到消息记录。
- LivingMemory 等上游插件记录。
- `[星汐/权限守卫]`、`[星汐]`、`[星汐/联网]` 记录。
- 最终 `Prepare to send` 或发送结果。

提交前按照隐私说明脱敏，并注明哪些占位符代表同一账号或同一群。
