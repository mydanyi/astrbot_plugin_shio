# 星汐 0.2.4：让数字仿生人格真正进入群聊

0.2.4 汇总了 0.2 系列的第一轮真实群聊验证。星汐不再只加工已经产生的回复，而是具备有限群聊运行时：能听取未点名消息、等待群友说完、选择是否接话，并在严格白名单和冷却约束下低频主动开启话题。

## 本次重点

- 按平台、机器人、会话、群和发送者隔离身份与上下文，降低串人、串群和误认主人的风险。
- Planner 支持主／备用 Provider、硬超时和本地安全降级；DeepSeek 官方 V4 规划请求会按调用关闭思考，不改变主对话配置。
- 兼容 Meme Manager 的 `search_memes` 语义 Tool 模式，同时与联网资料工具、主人 Agent 权限完全分流。
- 拦截 DeepSeek V4 偶发泄漏到正文中的 DSML 工具协议；无工具重写仍失败时会硬阻断，发送前再检查一次。
- 新增弱反馈表达排序、主动参与隐私边界及 61 项自动化回归测试。

## 升级安全

- 未点名自然接话和静默主动话题默认关闭。
- 静默主动话题还要求非空群白名单；空白名单不会向任何群发送。
- 两类主动发言都不会获得联网、浏览器、Shell、文件、代码或主人 Agent 工具。
- 升级后请重新检查主人 ID、普通用户只读工具白名单及主动参与群白名单。

## 安装包

下载 `astrbot_plugin_shio_v0.2.4_upload.zip`，在 AstrBot WebUI 的插件管理页面直接上传。安装包只有一个顶层 `astrbot_plugin_shio/` 目录。

支持 AstrBot `>=4.26.7,<5`，当前主要验证平台为 QQ `aiocqhttp`。建议先在测试群运行一至两天，再逐步开放主动参与功能。
