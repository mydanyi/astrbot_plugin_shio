# P6-05 独立低置信群体信号

## 结论

其他群友对当前机器人回复的相邻反应现在进入独立的 `group_expression_feedback`，不再修改个人关系、主人/群友身份、高置信表达反馈或任何用户画像。

群体信号只回答一个窄问题：某个 scope 中，某类表达近期获得的群体气氛偏正面还是偏负面。它不是“谁喜欢谁”的关系证据。

## 数据边界

每条聚合项只保存：

- scope；
- expression ID；
- 有界分数；
- 聚合样本数；
- 最近观察时间。

不会保存原始问题、机器人回复、反馈正文、reviewer ID、内部 reply ID 或平台 message ID。

## 更新规则

- 普通相邻其他用户反馈：权重 0.08。
- 其他用户精确引用/reaction：关联相关性更高，但仍只进入群体通道，权重 0.12。
- 目标本人高置信反馈继续进入个人画像和高置信 `expression_feedback`，不会重复进入群体信号。
- 每个 reviewer 对同一轮回复最多贡献一次。
- 明确引用了无关消息或 reaction 指向无关消息时完全忽略，不归因给当前回复。

## 衰减和上限

- 分数限制在 `[-0.5, 0.5]`。
- 对外提供的弱调整限制在 `[-0.25, 0.25]`。
- 半衰期 6 小时，旧群体气氛自动衰减。
- 最多保留 128 个 scope，每个 scope 最多 64 个 expression；达到上限时淘汰最旧聚合项。
- 样本计数最多 1000，防止无界增长。

## 持久化

`social_state.json` 升级为 version 2，并增加仅含聚合量的 `group_expression_feedback`。旧 version 1 数据仍可读取；新字段缺失时从空群体信号继续。

## 验证

回归覆盖：

- 其他群友相邻反馈只进入群体信号；
- 精确引用的其他用户不污染目标画像或高置信表达反馈；
- 目标本人反馈只进入高置信通道；
- 引用/reaction 指向无关消息时不归因；
- 6 小时半衰期；
- 聚合状态可安全保存和重载，文件不含正文、reviewer 或 reply ID；
- 128 scope / 64 expression 容量上限。

完整测试：431 项执行，428 通过，3 项既有 expected failure。`git diff --check` 通过。

## 边界

- 当前只建立信号和安全查询 API，尚未让它自动改 Prompt。
- 后续只能以弱权重参与可撤销的表达排序，不能改变身份、关系或工具权限。
- 本层没有部署，没有修改第三方插件，没有 Git 写操作。
