# P5-05 最小严重违规 OutputValidator 报告

## 结论

P5-05 已完成。新增 `OutputValidatorV2`，只判定会破坏正确性、身份边界或可见协议的严重问题，不再把“风格不够像”“没用口头禅”“情绪不明显”“稍显机械”或“轻微重复”当成重写理由。

## 检查范围

- 确定性解析后回复为空；
- request/result 与当前可信 target message/sender 绑定不一致；
- 原始生成泄漏工具/通道协议；
- 原始生成泄漏 hidden thought/analysis/commentary 或其他内部推理；
- 非主人被称作主人或得到主关系专属亲密；
- 未被当前消息要求的主要语言切换；
- 无可信事实支持的角色线下经历；
- 无可信事实支持的当前价格/行情断言；
- typed semantic requirement 没有任何一个允许表达；
- 出现当前目标明确禁止使用的事实片段。

## 明确不检查

- 是否足够傲娇、活泼或可爱；
- 是否使用口头禅；
- 是否出现指定台词；
- 普通语气是否有点平淡或机械；
- 轻微重复、软长度偏好和普通格式审美。

这些属于人格轨迹、一次生成 Prompt、离线质量评估和后续渐进学习，不应触发生产二次改写。

## 处置类型

- 无 issue：`pass`；
- 严重但目标仍可信：`repair_once`；
- 空结果或 target binding 错误：validator 标为 `block`，由 P5-06 进一步决定空结果是否允许唯一一次修复；target 错误始终闭锁。
