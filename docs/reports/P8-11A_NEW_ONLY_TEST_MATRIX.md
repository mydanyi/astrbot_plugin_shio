# P8-11A New-only 失败回归矩阵

## 结论

在实现前新增 11 个脱敏入口用例，旧实现稳定出现 4 个 scope 枚举错误和 9 个链路失败，证明测试确实覆盖了“范围不存在、复杂轮次回旧 Planner、引用/多模态回旧、缺目标不闭锁、工具回环丢状态”等问题。实现后 11/11 通过。

## 覆盖

- 可信主人/群友，群聊/私聊。
- 普通聊天、复杂内容、`/task`、联网工具。
- 显式引用、图片、音频。
- typed 工具结果回环。
- 连续角色口癖属于软质量，不触发旧通用重写器。
- 缺失可信 message target 时停止事件，Provider/旧 Planner 调用均为 0。

测试与报告均未保存真实群聊全文、真实用户 ID、工具参数或凭据。
