# 星汐 0.2.0：从“回复加工”走向“群聊参与”

0.2.0 增加了第一版持续群聊运行时。星汐现在可以听取未点名消息，先等待群友说完，再决定保持倾听、继续等待或自然接话；也可以在明确白名单群长时间安静后，低频开启一个轻话题。

## 升级安全

- “允许未被点名时自然接话”默认关闭。
- “长时间安静后主动发起话题”默认关闭。
- 静默主动话题还要求非空群白名单；即使误开开关，空白名单也不会发送。
- 两类主动发言都固定清空全部工具，即使目标消息来自主人也不会进入 Agent 链。
- 建议先只在测试群开启自然接话，观察 `[星汐/群聊参与]` 调试日志，再调整阈值、冷却和每小时上限。

## 新增数据文件

`data/plugin_data/astrbot_plugin_shio/social_state.json` 保存按平台、机器人、群和用户隔离的互动次数、正负反馈与表达权重。它不保存聊天原文或机器人回复原文，但键中含可关联作用域，备份与反馈时仍应作为敏感文件处理。

## 推荐起步配置

```text
允许未被点名时自然接话：开启
自然接话群白名单：只填测试群
接话前静默去抖：4 秒
自然接话阈值：4.2
自然接话冷却：45 秒
每群每小时自然接话上限：8
长时间安静后主动发起话题：暂时关闭
```

确认一两天没有抢话或串人后，再按需要开启静默主动话题，并单独填写群白名单、允许时段、每日上限和至少数小时的冷却。
