# 常见问题

## 安装后不回复，先看哪里？

确认 AstrBot 版本在 4.27.4–4.28.2 范围内，QQ 已连接，Shio 已加载并启用，再检查：

1. 普通用户 QQ 或群号是否填入“聊天范围”，是否也在禁止名单中。
2. 当前消息是否 @ 或引用机器人，或者满足名称唤醒设置。
3. 未点名消息是否开启“允许自然参与”，并填写了自然参与群号。
4. 主聊天模型是否可用，是否仍有排队或等待合并的消息。
5. 发送前审核是否拦截了回复。查看后台审核结果，并按需开启主人故障通知。

主人可以绕过普通入口名单，但主人在群里未点名的闲聊仍按自然参与规则判断。

## 为什么自然参与设成 100%，它还是不说话？

参与概率在模型判断“适合接话”之后生效。冷却、频率上限、群号范围和模型判断都会影响参与机会。

开启 AstrBot 的“群聊消息记录注入上下文”，让参与判断有更多语境；同时检查参与判断模型、历史条数、参与规则和时限。模型不可用、超时或认为应该等待时，机器人会保持安静。

自然参与会参考当前人格，不要求同时开启“角色化自然表达”。

## 它会在没人说话时主动开启话题吗？

当前版本的自然参与由真实群消息触发，暂不包含冷群无新消息时主动开场或定时主动关心。

## 为什么回复变慢了？

一轮对话可能依次经过连续消息等待、智能判断、主模型与工具、发送前审核和模型分段。开启回复准备还会增加一次辅助判断。气泡间隔则影响后续文字的发送时间。

可以先使用“直接识别”名称、按句分段，并暂时关闭审核与回复准备作对比。若仍然很慢，再检查主模型和工具。辅助模型时限通常是主选与备用模型共用的总预算，带长思考的模型需要更多时间。

## 角色语气不符合设定，怎么办？

先检查 AstrBot 当前会话实际使用的人格，再看主聊天模型、近期历史和召回记忆是否带入了不相关内容。

“角色化自然表达”沿用当前人格，不会替你创建或覆盖人格。主人风格只在 AstrBot 确认当前发送者是主人时生效。开启审核后，也要检查审核规则是否把角色语气改成了统一的客服表达。

## 为什么气泡过多、过少，或者没分段？

由 Shio 控制气泡时，请关闭 AstrBot 自带分段，避免重复拆分。最多气泡数是上限，不要求每轮凑满；短回复、完整代码块或无法合理切分的文本可以保留单段。

TTS、文字转图片和 QQ 转发等功能会转换整条结果，这时可能保留 AstrBot 标准发送。表情包图片不计入文字段数，图片数量需要在 Meme Manager 中设置。

## 为什么没有表情包？

表情包由 Meme Manager 选择。检查它是否启用、图片是否已安装、当前会话是否绑定了图片包，以及选图方式和模型是否可用。

是否配图与模型思考开关无关，也不要求开启 Shio 的角色表达模块。不同 Meme 模式使用的概率与提示词规则不同，不能把某个概率值理解为所有模式每轮必发。若正文出现 `&&meme:...&&` 一类标记，请提供 Shio、Meme 和 AstrBot 版本及本轮日志。

## 停用插件后为什么还会复读或答非所问？

停用不会删除已经保存的聊天历史或第三方记忆。先保留旧会话，再用新会话作对比，检查重复内容是否来自历史、记忆召回或模型本身。

如果只在某个旧会话发生，先备份再处理该会话；不要直接清空整个 AstrBot 数据库或所有长期记忆。

## 为什么模型选择列表是空的？

先在 AstrBot 中创建并启用聊天模型，然后重载 Shio、刷新设置页。Shio 直接使用官方模型选择列表，不需要手填内部模型 ID。

名称判断、自然参与、审核、模型分段和回复准备分别设置流式开关。模型留空继承当前聊天模型，但不会自动继承主对话的流式设置。

## 为什么群聊图片没有被理解？

使用 AstrBot 的“群聊消息记录注入上下文”，并检查图片转述模型或多模态模型。“持久化群聊消息记录”保存的媒体占位符不等于图片内容。

若后台出现 QQ 临时图片链接下载 HTTP 400，问题发生在媒体下载环节。检查 AstrBot、NapCat 的版本和对应日志，以及链接是否失效。不要公开完整临时下载链接。

## 开启故障通知后，主人为什么没收到？

首次开启后，需要主人给机器人发一条真实私聊，以保存通知地址。再检查：

- AstrBot 管理员名单是否正确，主人是否仍在名单中。
- 是否开启“私聊通知主人”和对应故障类型。
- 是否在同类故障去重期或勿扰时间内。
- QQ 是否在线，当前平台是否允许主动私聊。

通知针对正式回复终局失败或审核拦截，不转发所有后台日志。自然参与决定不回复也不算故障。“已提交”表示已交给 AstrBot 发送接口，不能证明 QQ 一定送达。

## 保存设置时回复中断了？

保存设置会触发插件重载。Shio 按“重载与停用 → 等待回复完成”等待已有任务，超时后停止剩余回复，并按通知设置尝试私聊主人。已发送的气泡不会撤回，未完成内容不会自动补发。

尽量在空闲时修改设置。强制终止 AstrBot 进程不保证等待已有回复结束。

## 如何反馈问题？

在 [Issues](https://github.com/mydanyi/astrbot_plugin_shio/issues) 提供版本、平台、相关插件、影响该功能的设置、复现步骤与本轮脱敏日志。说明是在新会话还是旧会话出现，以及当时是否保存设置或重载。

请遮住 API Key、Cookie、Token、真实 QQ 号、群号和私人内容。无需上传生产数据库。
