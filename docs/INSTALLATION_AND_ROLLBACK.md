# 安装、升级与回退

## 安装前

Shio **0.5.18** 适用于 AstrBot **4.27.4–4.28.2**，当前支持 QQ / OneBot v11（`aiocqhttp`）。先在 AstrBot 中完成 QQ 连接、聊天模型和人格设置，并确认普通对话能够正常回复。

长期记忆、联网搜索与表情包是可选搭配，不是安装 Shio 的前提。

## 安装

在 AstrBot 网页打开插件管理，使用仓库地址安装：

```text
https://github.com/mydanyi/astrbot_plugin_shio
```

也可以从 [Releases](https://github.com/mydanyi/astrbot_plugin_shio/releases/latest) 下载 `astrbot_plugin_shio-0.5.18.zip`，通过插件管理上传安装。

安装成功后，列表中应显示“星汐”和版本 `0.5.18`。打开插件设置，配置：

1. **聊天范围**：私聊 QQ 名单与群号名单留空时，Shio 不限制对应的聊天范围；填写后，普通用户只允许进入名单内的私聊或群。主人身份使用 AstrBot 的管理员设置。
2. **自然参与**：想让它参与未被点名的群聊时，开启允许自然参与并填写参与群号。
3. **角色化自然表达**：按需开启，沿用 AstrBot 中已经设置的人格。
4. **文字气泡**：选择单条发送、按句分段或模型分段。由 Shio 分段时，关闭 AstrBot 自带分段。

模型字段从已有模型中选择即可。每项设置的含义、留空效果与默认值见[设置指南](SETTINGS_GUIDE.md)。

## 配合其他插件

- **LivingMemory**：按它的说明设置记忆模型、存储与召回。
- **AnySearch**：配置可用的搜索服务，并在 AstrBot 中启用相应工具。
- **Meme Manager**：先安装表情包并配置使用规则，再选择配图方式和图片数量。

普通群友需要使用某个工具时，检查 Shio 的“普通群友工具范围”以及 AstrBot 和工具插件自身的权限。Shio 不会自动启用被 AstrBot 关闭的工具。

## 第一次聊天

先从一条私聊或测试群 @ 开始，再按需要调整自然参与、气泡与审核。想让模型看见群里前面的对话，在 AstrBot 中开启“群聊消息记录注入上下文”。

自然参与、审核和回复准备会增加模型调用。初次调整时每次改变一个模块，更容易判断哪项设置影响了体验。

## 升级

升级前备份现有插件目录、Shio 配置、AstrBot 配置及需要保留的会话数据，然后在插件管理中更新或上传新安装包。发布包不含生产配置或数据库。

本次 0.5.18 没有新增配置字段，现有配置可以保留。新安装使用当前默认值；升级不会主动重置已经填写的人格、模型或规则。

保存设置或重载时，Shio 会按“重载与停用”的等待时间处理已接收的回复。为避免等待中的对话被中断，建议选择空闲时更新。

## 回退

如果更新后出现异常：

1. 在插件管理中停用 Shio，等待现有回复结束。
2. 保存版本、相关设置及脱敏日志。
3. 恢复备份的插件目录，或安装此前保留的 ZIP。
4. 重载插件；必要时恢复对应配置备份。

回退插件代码不会撤销已经保存的聊天历史。不要用删除整个 AstrBot 数据目录或清空所有记忆的方式回退插件。遇到具体问题，请参考[故障排查](TROUBLESHOOTING.md)。
